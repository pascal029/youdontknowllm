How it works

Three steps, no setup

  1. Pick a model

    One of 5 small models (0.6B–1.7B parameters) downloaded once into your browser, or any OpenAI-compatible API such as OpenAI or Ollama.

  2. Ask something

    Change the system prompt, switch tools on or off, or write your own tool with a JSON Schema and a few lines of JavaScript.

  3. Watch what happens

    Follow every step of the loop, and see the context window and tokens per second update as the model generates.

FAQ

Questions

Is it free?

Yes. It runs in your browser and the code is on GitHub. Local models cost nothing to run. If you connect a paid API, you pay that provider directly.

What do I need to run a model locally?

A browser with WebGPU (recent Chrome or Edge) and roughly 1–2 GB of free GPU memory. The model downloads once and is cached.

Is my data sent anywhere?

With a local model, nothing leaves your computer. With an API, your messages go only to the API address you enter, and your key is never saved: you enter it each visit.

Which models can I use?

Locally: Qwen3 0.6B, Llama 3.2 1B, Qwen2.5 1.5B, SmolLM2 1.7B and Qwen3 1.7B. Remotely: any model behind an OpenAI-compatible /chat/completions endpoint.
